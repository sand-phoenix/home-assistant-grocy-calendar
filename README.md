# Grocy Meal Plan Calendar

Read-only Home Assistant calendar integration for Grocy meal plans.

It reads `objects/meal_plan` and `objects/recipes` and exposes an all-day `calendar.grocy_meal_plan` entity. It does not create, modify, or delete Grocy records.

Install through HACS as a custom integration, then add **Grocy Meal Plan Calendar** in Home Assistant and supply the Grocy API URL and a read-only API key.
